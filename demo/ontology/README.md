# ontology

Chocolate factory scenario for `fabric-ontology`, in its standard scenario
shape (`ontology_config.json` + `tables/*.csv`).

- [`ontology_config.json`](ontology_config.json) -- tables, columns, types,
  keys, relationships for all three agent domains (Factory/Quality, Supply
  Chain, ERP/Orders).
- [`farm-preparation.md`](farm-preparation.md) -- why Farm Preparation
  (harvest, fermentation, drying, roasting, winnowing) is documented but not
  modelled as factory production stages.
- `tables/` -- dimension CSVs. `factory.csv`, `production_line.csv`,
  `production_stage.csv`, and `recipe.csv` are generated by
  [`../data-generation/run_seed_data.py`](../data-generation/run_seed_data.py)
  -- run that first. `sensor_reading`, `quality_check`, `batch`, and
  `line_status` are streamed at runtime by the data generator, not seeded
  here (`batch` is materialized in Silver from the generator's
  `batch_event` stream -- see the medallion-layers design memo).

## Checking it visually

[`generate_rdf.py`](generate_rdf.py) converts `ontology_config.json` into
`chocolate.rdf` (RDF/XML-OWL), the format
[microsoft/Ontology-Playground](https://github.com/microsoft/Ontology-Playground)
accepts on its hosted site
([microsoft.github.io/Ontology-Playground](https://microsoft.github.io/Ontology-Playground/))
with no setup. The Playground's JSON import is a legacy, disabled-by-default
feature with a different shape (`entityTypes`/`cardinality`) than our
`tables`/`relationships`, so RDF is the actual interoperable path — and per
the Playground's own docs, it's also the exact format Microsoft Fabric IQ
expects.

```bash
python generate_rdf.py          # regenerate chocolate.rdf after editing the config
```

Then on the Playground: Import/Export → Import → pick `chocolate.rdf`. All
17 classes and 19 relationships should appear on the canvas, grouped loosely
by domain via each class's icon/color (🏭 Factory/Quality, 🚚 Supply Chain,
🧾 ERP/Orders).

## Deploying into fabric-ontology

Copy this folder to
`sources/fabric-ontology/data/scenarios/chocolate/`, then register it in
`sources/fabric-ontology/data/scenarios/scenarios.json` alongside `retail`
and `insurance` (`"type": "prebuilt"`, `"folder": "chocolate"`).
